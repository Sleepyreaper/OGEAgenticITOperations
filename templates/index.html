The Agent Squad

One coordinator and five specialists. Code (not the model) routes each finding to the specialist that owns it; specialists analyze live Azure evidence in parallel, challenge each other when the stakes are high, and the coordinator delivers one evidence-cited recommendation. Every agent is read-only — changes go through human approval.

How the Squad Works

  1. Collect — deterministic collectors read Azure (Cost Management, Monitor, Defender, Policy, Backup, Update Manager, Key Vault, Activity Log…) into cited findings. No AI involved.
  2. Route — code maps each finding category to its owning specialist and decides whether a debate is needed (cross-domain, high/critical, or customer-impacting).
  3. Analyze in parallel — each selected specialist reasons over its evidence and may call read-only tools for more detail.
  4. Challenge — in a debate, each specialist rebuts the others before anything is concluded.
  5. Synthesize — the coordinator produces one recommendation; every claim must cite a finding ID, and citations are validated.
  6. Approve — remediation becomes a reviewable proposal (Azure DevOps work item / PR, Terraform/CLI) — never auto-executed.

ZeroOps: SRE Agent + Agent Squad

The Azure SRE Agent watches repos, logs and monitoring and fixes the runbook-shaped problems itself. When an incident is cross-domain, business-impacting or has no safe runbook, it escalates to the squad over MCP. The squad reasons about impact and returns a fix or script that a human approves. Nothing changes without approval.
