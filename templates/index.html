      How the Squad Works

      1. Collect — deterministic collectors read Azure (Cost Management, Monitor, Defender, Policy, Backup, Update Manager, Key Vault, Activity Log…) into cited findings. No AI involved.
      2. Route — code maps each finding category to its owning specialist and decides whether a debate is needed (cross-domain, high/critical, or customer-impacting).
      3. Analyze in parallel — each selected specialist reasons over its evidence and may call read-only tools for more detail.
      4. Challenge — in a debate, each specialist rebuts the others before anything is concluded.
      5. Synthesize — the coordinator produces one recommendation; every claim must cite a finding ID, and citations are validated.
      6. Approve — remediation becomes a reviewable proposal (Azure DevOps work item / PR, Terraform/CLI) — never auto-executed. An approval is a record, not an execution.

      ZeroOps: SRE Agent + Agent Squad

      The Azure SRE Agent watches repos, logs and monitoring and fixes the runbook-shaped problems itself. When an incident is cross-domain, business-impacting or has no safe runbook, it escalates to the squad over MCP. The squad reasons about impact and returns a fix or script for a human to review. This app never applies a change; recorded approvals and operator closures are not execution or verification. for recorded proof.
